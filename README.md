## Project 3: Superstore Performance & Sales Analytics Dashboard

### Overview

An interactive Power BI dashboard developed to analyze Superstore sales, profit margins, regional performance, product categories, customer segments, and geographical distribution.

### Project Objective

The objective of this project is to analyze sales and profitability data and create an interactive dashboard that helps users understand business performance and identify profitable and underperforming areas.

### Tools Used

- Power BI
- Power Query
- DAX
- Excel/CSV
- Card Visuals
- Bar Charts
- Line Charts
- Waterfall Charts
- Interactive Slicers
- Map Visualizations

### Key Insights

- Total Sales: $2.3M
- Total Profit: $286K
- Overall Profit Margin: 12.47%
- Technology was the highest-performing category.
- The dashboard highlights sales and profit performance across different regions and segments.
- Geographic and customer-level analysis provides additional insights into business performance.
- Interactive filters allow users to analyze performance by state, city, and year.
